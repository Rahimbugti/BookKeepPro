# BookKeepPro

A modern, responsive Bookkeeping & Accounting Services web application featuring:
- **Editorial Design & Typography:** Dark/Light contrast, serif typography, and rich visual styling.
- **Scroll-Triggered Blur Animations:** Dynamic blur-to-clear entrance animations across all sections.
- **Multi-Currency Engine:** Instant currency conversion for USD ($), CAD ($), AUD ($), and GBP (£).
- **Interactive Pricing Calculators:** Step-by-step workload and property management estimators.
- **Booking & Consultation Modals:** Direct scheduling pre-wired with client validation.
- **Responsive Architecture:** Built with React, TypeScript, Tailwind CSS, and Vite.

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm / yarn / pnpm

### Installation & Run Locally

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
